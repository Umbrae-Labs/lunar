# 主题约束

## 色彩体系

[MUST] 产品界面以黑、白与中性灰为基础，导航与选择的激活状态使用统一的语义蓝色。

[MUST] 主题颜色通过 HeroUI Native 与 Uniwind 的语义变量表达。

[MUST] 阅读器组件的深浅模式跟随应用全局设定。纸页颜色属于阅读内容配色，浅色与深色模式各自提供五种颜色并分别保存选择。

[MUST] 浅色主题与深色主题声明相同的语义变量集合。

[MUST] 业务组件仅引用语义颜色，禁止建立业务专属灰阶或硬编码界面颜色。

[MUST] 书籍封面、EPUB 内容与具有明确语义的状态颜色可以保留内容自身颜色。

[MUST] 同一控件的图标与文字同时表达激活状态时，两者使用相同的激活颜色。

## 深色主题

[MUST] 深色主题的页面背景为纯黑。

[MUST] 深色主题的组件表面颜色浅于页面背景，并依据层级逐级变亮。

[MUST] 深色主题的文字、边界与交互状态保持清晰的明度差异。

## 浅色主题

[MUST] 浅色主题的组件主表面为纯白。

[MUST] 浅色主题的页面背景为浅灰，明度低于组件主表面；普通浅色阅读纸页与页面背景使用同一浅灰色。当前浅灰设计值为 `#F8F8FA`。

[MUST] 选择类弹层与阅读设置抽屉的承载面使用浅灰背景，浮于其上的选项、按钮及操作部件使用纯白主表面；底部导航栏也使用纯白主表面。

[MUST] 更高的视觉层级使用更浅的表面颜色；轨道、分隔线与其他内凹区域允许使用较深的中性灰。

[MUST] 导航标签、单选选项与排版选项的激活状态使用语义蓝色；浅色主题的排版选项通过蓝色文字表达选中状态。

[MUST] 浅色主题的文字、边界与交互状态保持清晰的明度差异。
