# 阅读内核约束

## 边界

[MUST] EPUB 阅读核心存放于 `apps/mobile/src/reader`。

[MUST] `apps/mobile/src/reader` 通过自身公开入口向业务层提供阅读能力。

[MUST] 业务页面与业务组件隔离 `@umbrae-labs/rito-rn`、Skia 绘制对象及阅读内核内部状态。

[MUST] 应用层的 Rito 适配限定于 `apps/mobile/src/reader/rito` 与 `apps/mobile/src/reader/runtime/pagination`，原生协议实现位于 独立包 `@umbrae-labs/rito-rn`。

[MUST] `apps/mobile/src/reader/rito`、`apps/mobile/src/reader/runtime/pagination` 与 独立包 `@umbrae-labs/rito-rn` 共同构成 Rito 版本差异的适配边界。

## 内部分层

[MUST] `contracts` 仅定义阅读内核公开类型与固定错误契约。

[MUST] `typography` 仅负责排版默认值、输入规范化与版面标识生成，保持平台无关。

[MUST] `runtime` 仅负责阅读会话、版面修订、分页调度与资源生命周期。

[MUST] `runtime/core` 仅负责阅读运行时、阅读会话接口与运行时诊断。

[MUST] `runtime/pagination` 仅负责分页后端、分页调度、Rito 分页适配与分页相关资源解析。

[MUST] `runtime/cache` 仅负责帧缓存、渲染资源缓存与阅读操作串行化。

[MUST] `rito` 仅负责 Rito 适配、版面配置转换与阅读位置处理。

[MUST] `skia` 仅负责文字测量、字体、图片、绘制命令与画面编译。

[MUST] `skia/fonts` 管理字体注册、字体匹配与原生字体资源生命周期。

[MUST] `skia/text` 管理 Paragraph 创建、字形塑造与文字测量。

[MUST] `skia/images` 管理图片解码与图片缓存。

[MUST] `skia/rendering` 管理 DisplayList 执行、Picture 编译与 Canvas 表面。

[MUST] `skia/anime/core` 仅保存翻页效果共享的类型、组合契约、画面身份、数学函数与并发规则，不得依赖 React Hook、原生 composer 适配或具体动画实现。

[MUST] `skia/anime/effects/<effect>` 以动画为单位保存视觉计算、手势进度、释放判定、完成与回弹时长、缓动函数及专属能力配置；每个动画必须实现 `core` 定义的统一组合契约。

[MUST] 动画兼容名称仅由 `skia/anime/effects` 注册表解析，控制器、手势和原生适配不得依据动画名称选择具体策略。

[MUST] 单个动画包含多个算法或绘制模块时使用动画名称子目录，`curl` 的几何计算、进度换算、网格绘制与时序策略共同归入 `effects/curl`。

[MUST] `skia/anime/gesture` 仅负责手势采样、通用坐标换算、调用当前动画策略及 UI Runtime 命令发送，不得保存具体动画的进度、释放或回弹策略，不得提交阅读运行时导航。

[MUST] `skia/anime/native` 仅负责 C++ composer 协议、Canvas 绑定、页面呈现与画面库存的提交、事件分派与原生能力探测。

[MUST] `skia/anime/controller` 负责选择统一动画实现并组合交互翻页、RN 导航、运行时预备操作与运行时对 composer 的跟随；公开 Hook 必须保持为轻量组合层，细分状态由对应控制器持有。

[MUST] 翻页进行中的状态由控制器与 composer 在 React 之外持有。阅读页面只订阅输入门控所需的粗粒度状态；翻页的中间状态变化不得重新渲染阅读页面。

[MUST] 手势回调必须保持稳定，输入门控通过 UI Runtime 可读的共享状态表达，翻页提交与快照变化不得重建手势对象。

[MUST] `skia/anime` 的内部依赖以 `core` 为基础，由 `effects` 实现组合契约，`native` 与 `gesture` 通过契约使用当前动画能力，并由 `controller` 完成组合；内部模块不得通过顶层公开入口反向引用自身。

[MUST] `interaction` 仅负责命中检测、文本选区、页面文本句段与当前页可访问性语义。

## 会话与版面约束

[MUST] 阅读业务只能通过 `apps/mobile/src/reader` 的公开入口访问运行时能力。

[MUST] 阅读会话中的分页工件视为不可变值，版面变化通过新的修订标识表达。

[MUST] 具有源文本映射的文字命中数据在参与持久化范围计算前必须具备源节点坐标与 UTF-16 偏移，保持选区、搜索结果与持久化标记的范围语义一致。

[MUST] Rito 分页工件的文字命中项允许缺少源节点坐标；阅读内核必须通过 Rito 搜索结果解析持久化源范围，并使查询文本遵循页面文本索引的单换行规范。

[MUST] 选区显示文本与源范围查询文本保持不同语义：显示文本可以保留段落间距，源范围查询文本必须将连续段落换行规范为单换行，以匹配 Rito 页面文本索引。

[MUST] 工件身份与画面身份保持独立，工件身份不得替代画面身份参与渲染资源复用。

[MUST] 帧的修订标识、页序位置与画面身份必须共同满足渲染一致性要求。

[MUST] 空帧、页序位置不匹配的帧与已失效修订的帧不得进入渲染表面。

[MUST] 前台导航与后台分页对同一阅读会话的状态变更必须保持确定的先后顺序。

[MUST] 阅读会话结束后，属于该会话的分页工件、图片资源、字体资源与画面资源必须进入终止状态。

## 翻页缓存与绘制约束

[MUST] 页面叠加层按来源组织。每个来源提供适用于所有绘制页面的同步结果，并可以为当前页提供精化结果；精化结果只替换所属来源的当前页结果，渲染表面合并全部来源。

[MUST] 页面文本句段的命中数据范围只对生成它的帧有效；跨帧定位依次使用来源范围与文本匹配，来源范围对应的文本与记录不一致时不得采用。

[MUST] 持久化标记的绘制数据依据所属页面的章节与来源坐标生成，并随源页和目标页共同参与翻页绘制。

[MUST] 翻页期间保留的页面使用自身工件携带的章节身份，预备目标页与当前阅读快照的章节允许存在差异。

[MUST] `slide` 翻页采用由上一页、当前页与下一页组成的逻辑三页缓存窗口，以支持相邻页面连续往返访问。

[MUST] 逻辑三页缓存窗口仅表达当前页的可达邻域；一次交互只绘制源页与目标页，并保持两页边缘相连和位移互补。

[MUST] 手势采样必须持续驱动源页与目标页的中间状态，松手后的提交动画或回弹动画必须从最后一次采样状态继续。

[MUST] 翻页源页与目标页的画面资源必须保留到 composer 完成该翻页之后；静止页的画面资源必须保留到 composer 呈现另一页之后。

[SHOULD] 原生分页工件的常驻数量遵守资源上限，逻辑三页缓存窗口不得被实现为三个原生分页工件永久常驻。

[MUST] 预览相邻页时私有槽位按真实翻页的规则临时标注，使预览页的画面身份与随后翻到该页时一致；预览结束后必须恢复全部私有槽位，预览期间后台分页暂停。槽位到画面的对应关系必须一并恢复；预览开始前已在途的后台分页结果，只能在槽位恢复后据以发布快照。

## 原生翻页合成约束

[MUST] 原生 C++ composer 是阅读页面的唯一呈现者，负责静止页、翻页动画、纹理生命周期与呈现事件；阅读 Canvas 只绘制位于其上的临时界面，包括文本选区与书签下拉标记，不得绘制页面内容。

[MUST] 原生 composer 不得改变阅读运行时的页序、修订标识或画面身份语义。

[MUST] 原生 composer 的实现位于 `apps/mobile/modules/reader-composer`，编译进 React Native Skia 的原生库，与其共用 Skia 构建、渲染线程与 GPU 上下文；项目维护的 React Native Skia 补丁只提供图片视图扩展点与渲染线程调度，不得承载 composer 逻辑。

[MUST] 原生 composer 的协议适配限定于 `apps/mobile/src/reader/skia/anime` 与 `apps/mobile/modules/reader-composer`，业务层不得调用原生 composer 接口。

[MUST] 阅读页面不保留 JS 翻页实现。原生 composer 缺失、协议版本不匹配或 Canvas 尚未准备完成时，渲染表面只显示纸张底色。

[MUST] 订阅方显示的页面变化后，渲染表面必须将该页交给 composer 呈现。RN 导航到达的页面携带导航方向，composer 从当前静止页翻到该页；其余页面变化直接切换。

[MUST] composer 自行领先运行时翻到的页面，在运行时追上之前不得被运行时途经的页面替换；运行时无法跟随时必须强制 composer 呈现运行时所在页。

[MUST] 单页与双页均由 composer 合成。双页卷页以书脊为轴翻转半页，手势坐标按半页宽度归一化；`slide` 移动整个视口。

[MUST] `slide` 仅移动正文画面；单页模式的章节标题与页脚进度由固定画面层绘制，并在目标页面身份更新后替换内容。

[MUST] 书签数量与书签状态不得关闭原生 `slide` 合成。书签标记归属可移动页面层，固定标题与页脚归属独立画面层；原生翻页与回弹必须保留两层的正确页面身份。

[MUST] 书签下拉期间由 composer 移动静止页，并以不含书签标记的页面画面呈现，书签下拉标记由阅读 Canvas 绘制。

[MUST] 原生纹理缓存标识必须包含书签与标注等绘制状态，阅读导航身份保持独立；绘制状态变化后不得复用旧外观的纹理。

[MUST] 同方向连续触发多个原生 `slide` 翻页时，所有在途动画必须合成为连续页面带的累计位移；后续动画不得从零位移覆盖前一动画，领先动画结束并移出队列时画面位置必须保持连续。

[MUST] 原生库存只能由阅读运行时解析的相邻页画面构成，并以可见页为起点逐页向外成链，每个方向至多两页。库存不得持有前台候选、不得改变可见工件，库存所用的分页工件在画面编译完成后必须释放。

[MUST] 原生手势卷页必须关联该拖拽自身 `prepareAdjacent()` 返回的预备操作；原生 composer 可以在该预备操作完成前接管拖拽，`consumed`、`completed` 与 `cancelled` 事件必须等待预备操作完成后再提交或取消它。预备失败时只能执行一次同方向的相邻页导航，使运行时与 composer 揭示的页面保持一致。原生 composer 接管的拖拽在运行时一侧已不存在时，必须取消该原生手势。

[MUST] composer 接管拖拽之前，页面保持静止；此时松手并判定提交的拖拽，由运行时完成导航后以携带方向的呈现播放翻页，判定取消的拖拽不产生动画。

[MUST] 翻页区点按可以在 UI 线程直接消费原生库存，由原生 composer 领先运行时翻页。点按落在链接、脚注、图片、高亮上，或存在文本选区、图片查看器以及未解析完成的高亮时，必须交由 RN 处理；拖拽、交互翻页提交与 RN 导航进行期间，以及 composer 未领先而订阅方尚未显示运行时所在页时，原生 composer 不得消费点按。

[MUST] UI 线程消费点按后必须立即通知 RN，并从此时起持续读取 composer 事件直至运行时跟随结束；点按的位移容差必须小于拖拽激活阈值，同一次触摸不得既由原生翻页又启动拖拽。

[MUST] 原生 composer 领先期间，阅读运行时必须按点按顺序逐页跟随：运行时已位于目标页时不再导航，位于源页时执行一次同方向的相邻页导航，二者皆非或导航后未到达目标页时停止跟随。跟随期间拖拽保持阻塞。

[MUST] 原生库存页纹理的页眉页脚必须与翻到该页后运行时发布的快照一致：预览页快照与翻页发布的快照由同一规则生成，章节标题取自该页自身；源页使用订阅方当前快照绘制，页面的页眉页脚信息变化后必须重新库存。

[MUST] 拖拽进行中、交互翻页提交完成前或运行时跟随原生 composer 期间的点按，在其结束后执行，同方向的每次点按各翻一页，且不得中断进行中的翻页。

[MUST] Android 阅读 Canvas 必须保持 TextureView 呈现；只有设备测试证明 composer 的中间帧在独立原生渲染线程的 SurfaceView 上连续呈现后，才允许通过 `opaque` 切换。

[MUST] 原生 composer 的完成、取消与开始事件必须关联唯一翻页编号，重复事件不得重复提交导航或重复释放画面资源。

## 滚动阅读约束

[MUST] 翻页模式分为左右翻页与上下滚动，作为独立于翻页动画的阅读设置持久化；上下滚动时排版请求使用 Rito 的 `scrolled` 版式，持久化的排版设置保留分页模式的 `spreadMode`。

[MUST] 上下滚动时由原生 composer 以页面带呈现窗口：每个窗口即一个跨页，由阅读运行时解析，并以可见窗口为起点紧贴其相邻窗口排列；滚动偏移只在 UI 线程更新，阅读 Canvas 只绘制固定的页眉、页脚及其纸张底色。

[MUST] 阅读线越过可见窗口时，运行时以相邻页导航逐窗跟随；窗口按绘制内容识别，私有槽位重排或整书排版接管后，同一窗口必须保持原有位置。订阅方显示页面带未持有的窗口时视为跳转，页面带从该窗口重建，并以 `targetBlockOffset` 将目标行置于内容区顶部。

[MUST] 滚动停止后，以阅读线所在行的源位置作为阅读位置；翻页控制器在上下滚动时不得订阅运行时或库存页面。

## 相邻页导航约束

[MUST] 相邻页索引统一由阅读运行时解析，手势层与渲染层不得使用 `spreadIndex + 1` 或 `spreadIndex - 1` 推导目标页。

[MUST] `spreadIndex` 仅表示当前修订中的私有渲染槽位，不得作为整本书中永久稳定的页序身份。

[MUST] 分页后端处理向前回翻的 `previous` 导航时允许重排私有槽位；上层必须使用运行时返回的源槽位与目标槽位完成画面准备和状态恢复。

[MUST] 交互翻页通过 `prepareAdjacent()` 准备相邻页，并且使用返回值携带的修订标识、方向、源槽位、目标槽位与目标画面身份。

[MUST] `prepareAdjacent()` 只能创建和准备未提交的候选工件，不得改变分页会话的可见工件或公开快照；候选工件只能由对应的提交操作采用。

[MUST] 每次成功的 `prepareAdjacent()` 必须由一次 `commitPreparedTurn()` 或 `cancelPreparedTurn()` 结束，预备结果不得脱离所属阅读会话继续使用。

[MUST] 预备目标页的快照必须表达目标页自身的书内位置与进度，不得复制源页的位置信息。

[MUST] `commitPreparedTurn()` 必须提交同一次预备操作生成的目标页，不得再次执行独立的相邻页导航。

[MUST] `cancelPreparedTurn()` 必须恢复预备前的可见工件与私有槽位，使公开快照继续指向原始源页。

[MUST] 预备、提交、取消与前台导航必须由运行时串行调度，后台分页不得在交互翻页期间改变可见页语义。

## 动画交接约束

[MUST] 翻页画面身份由修订标识、`spreadIndex` 与 `renderId` 共同确定，任何一项缺失或不匹配均不得视为同一目标画面。

[MUST] 私有槽位重排后，反向目标页允许与源页具有相同的 `spreadIndex`；此时必须通过 `renderId` 区分两幅画面。

[MUST] 翻页方向必须由交互意图或预备结果显式提供，不得根据源页与目标页的 `spreadIndex` 大小关系推断。

[MUST] 非拖拽翻页动画只能由显式导航意图或经过目标身份校验的快照变化触发。

[MUST] RN 导航的翻页方向必须在运行时发布目标快照的同一次通知中登记，目标页不得先以静态画面出现，再由翻页动画揭示；订阅方跳过的中间页不得保留翻页方向。原生 composer 领先运行时的点按翻页不登记翻页方向。

[MUST] 可见页在拖拽方向上没有相邻页时，拖拽不得开始翻页，源页保持静止。

[SHOULD] 翻页诊断信息记录手势编号、预备操作编号、方向、提交判定以及源页和目标页的完整画面身份，以便还原相邻页往返时序。

## 取舍约束

[SHOULD] 已完成工件的不可变性优先于因元数据变化重复生成相同画面。

[SHOULD] 前台导航响应优先于后台分页吞吐量。

[SHOULD] 缓存容量边界优先于无限期保留分页工件或渲染资源。

[SHOULD] 画面缓存依据画面身份复用，分页工件缓存依据工件身份管理。

[SHOULD] 章节边界的有限工件保留优先于全书工件常驻，允许再次访问时产生分页开销。

[SHOULD] 诊断信息默认保持关闭，并且不改变阅读状态语义。
