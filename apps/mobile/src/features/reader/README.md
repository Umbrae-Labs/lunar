# Reader feature

该目录负责阅读页面、工具栏、目录面板、排版设置、手势组合与出版物加载。页面通过 `src/reader` 公开接口使用阅读内核，并通过 `library` 公开入口取得书籍记录与受管文件能力契约。

业务 Hooks 按会话、书签、选区、标注、内容交互与界面控制分组，职责说明见 [Hooks 目录](hooks/README.md)。

阅读正文支持下拉添加或取消书签。手指纵向移动超过 12 个逻辑像素后，Skia 页面按移动距离的 60% 下移，书签与提示在同一画面内绘制，提示随页面移动并保持在正文上方；正文下移达到 96 个逻辑像素时，文字和箭头切换为松手提示。松手距离低于阈值或系统取消手势时，正文恢复原位。当前页有书签时，页边显示由 Skia 绘制的书签带，书签从屏幕顶端延伸到首行正文上方，并在翻页时随所属页面移动。下拉添加时红色书签带随即显示在露出的空白区域；书签轮廓保持原位，露出区域超过原书签高度后随之伸长；再次下拉并达到阈值后删除该页书签。书签记录保存于 SQLite，保存内容包含章节、源文本坐标和正文摘要。

底部“书签与标记”面板按添加时间展示两类记录。点击记录通过阅读内核的 `goToLocator` 定位正文；书签支持删除。记录使用源文本坐标，字号变化后继续定位对应文字。

设备验收应覆盖浅色与深色主题、阈值前松手、越过阈值后回拖、系统取消手势、横向翻页、长按选区、跨章节记录跳转、修改字号后的跳转，以及重新打开应用后的记录恢复。

应用设置开启“启动时继续阅读”后，冷启动入口会先查询最近更新的阅读状态，再创建阅读器路由。查询期间书架页面保持未挂载状态。原生开屏页持续显示到阅读画面、标记状态与绘制帧准备完成；发生读取错误时，开屏页退出并展示阅读器错误页面。指定页面的深层链接保持原始启动目标，书籍删除后关联的阅读状态由 SQLite 外键同步删除。
