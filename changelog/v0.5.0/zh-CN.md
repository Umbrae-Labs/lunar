### 新增

- 新增上下滚动阅读模式，可在排版面板中切换「左右翻页」与「上下滚动」；滚动停止后自动记录当前阅读位置，并支持长按选中文字进行高亮与笔记操作
- 新增阅读时「跟随系统亮度」选项，可在阅读外观面板与阅读设置中开关；关闭后沿用阅读外观中自定义的亮度
- 新增插件下载管理，可从插件管理与设置中的「下载记录」查看下载进度与书封，支持暂停、继续、失败自动重试、手动重试、删除记录及完成后直接阅读；插件可将下载内容打包为 EPUB 并自动加入书库
- 新增阅读界面插件悬浮快捷按钮，插件可向阅读页注册快捷操作，单个入口点击即用、多个入口展开菜单；按钮可自由拖动并吸附至屏幕左右两侧，位置自动保存并避让控制栏与系统栏
- 新增插件密钥管理，可在插件详情页配置公网 HTTPS 服务地址与密钥；密钥加密保存在本机且仅发送到指定服务地址，插件无法读取原文
- 插件网络能力新增流式响应支持，插件界面新增支持 CommonMark 的 Markdown 组件，默认不加载远程图片，链接仅在点击后由系统浏览器打开
- 插件 SDK 与 CLI 正式更名为 `@umbrae-labs/lunar-plugin-sdk` 与 `@umbrae-labs/lunar-plugin-cli` 并升级至 0.1.6，宿主继续兼容已安装的旧模块名插件

### 优化

- 阅读内核升级至 Rito RN 0.4.0，调整字号、间距、页边距等排版设置时复用当前阅读会话直接重排，无需重新读取和打开书籍；同时支持字体 OpenType 特性，改善竖排与组合字形显示
- 优化翻页响应与预加载，在 UI 线程直接响应边缘点按翻页并准确避让链接、脚注、图片与高亮区域；按翻页方向预取相邻页面并保留多方向页面缓冲，改善连续翻页与往返翻页的流畅度
- 优化单页仿真翻页背面显示，带书签的页面卷起时背面同步呈现镜像书签标记
- 优化书籍打开与重排的加载体验，新增与当前纸页配色融合的月相加载画面，并遵循系统减弱动态效果设置
- 优化 EPUB 导入、检查与打包读写方式，改用按条目流式读写 ZIP，避免一次性将整本 EPUB 解压至内存，降低大体积书籍导入时的内存占用
- 优化导航与界面视觉：底部导航栏与阅读控制栏采用毛玻璃半透明背景，系统窗口背景同步当前主题配色以减少页面切换时的边缘闪烁；全应用图标统一替换为 Lucide 图标，并统一开关与搜索框样式
- 简化插件列表交互，点击直接进入插件页面或插件设置，减少对长按操作的依赖
- 调整阅读统计时长格式，不足一小时的阅读时长改为按分钟显示

### 修复

- 修复在部分 Android 文件管理器中选择 `.lunar-plugin` 插件包时因 MIME 类型过滤导致无法选中文件的问题（#16 by @SXP-Simon）
- 修复快速退出或切换书籍时阅读器原生会话关闭的竞态问题，确保进行中的关闭流程完整等待后再释放资源（#13 by @SXP-Simon）
- 修复书库「返回顶部」按钮缺少背景色的问题
- 修复插件界面 `Button` 图标颜色未跟随按钮主题色，以及布局组件省略间距或内边距时的样式处理问题
- 修复 `lunar-plugin --help` 与 `-h` 被误判为未知命令的问题
